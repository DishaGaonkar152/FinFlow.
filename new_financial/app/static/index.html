01 AI features

Intelligence that explains.
People who decide.

FinFlow uses AI to explain every extracted metric and answer questions about your audit. The figures themselves are never changed by AI.

AI reasons for every metric

An LLM explains each metric's meaning, extraction evidence, confidence and validation results — not just flagged values.

Ask FinFlow assistant

A chatbot that answers questions using the data of the audit you have selected.

Agentic tool selection

A LangGraph agent picks each next tool — SEC retrieval, extraction, validation, XBRL lookup — over MCP.

Smart escalation

Confidence scores and validation rules decide which numbers need human judgment.

AI content is always labeled. When no AI provider is configured, clearly marked rule-based answers are used instead.
